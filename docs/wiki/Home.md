# PraWe-miTnegA Wiki

PraWe-miTnegA is an early-stage open-source project for temporal security fuzzing and forensic analysis of AI-agent
workflows. Its engine, ChronoFuzz, will vary timing, event order, retries, callbacks and expirations. The first test pack,
AuthorityDecay, focuses on the lifetime of approvals and delegated work.

**Status:** early. No production-agent vulnerability detection or integration exists yet. The prototype models a synthetic
approval check; a deliberately faulty caching mode demonstrates a failed invariant.
